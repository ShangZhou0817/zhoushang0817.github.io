# Shang Zhou's Personal Website

Source for Shang Zhou's personal website, live at <https://shangzhou.me>.

Built with Jekyll using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Local preview

```bash
bundle install   # first time only
bundle exec jekyll serve --livereload
```

Then open <http://localhost:4000>.
